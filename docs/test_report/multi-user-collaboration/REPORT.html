⚠️ better-sqlite3 ABI 失败说明（环境问题）

26 个依赖 DB 的 vitest 文件报错：NODE_MODULE_VERSION 127 vs 137。better-sqlite3 原生绑定编译于 Node 22（MODULE_VERSION 127），系统 node 为 24.18.0（MODULE_VERSION 137）。

证据：main 基线同样失败

切换到 main 分支跑 tests/units/workflows.test.ts 出现相同 ABI 错误，证明此为既有环境问题，非本次代码引入。生产 9999 应用运行于 nvm Node v22.23.1，与绑定匹配，运行正常。集成测试在 9998 隔离实例（同样 Node v22）上完成，DB 读写全程正常。

Regression ↑ better-sqlite3: NODE_MODULE_VERSION 127 (Node 22) ≠ 137 (Node 24)
→ 既有环境约束，非本次缺陷

编排者-工作者（串行 + 验收）

调研员→ 开发→ 评审→ 验收 gate

向后兼容：等价 legacy 单 agent 串行链 + 验收 gate。

对等模式（并行 + 文件扇入）

质量派 ┃ 效能派 ┃ 治理派

⇣ 文件扇入

shellCheck gate

各 agent dependsOn 为空，并行写 peer/*.md，gate 校验 N 文件齐备。

批评对抗（producer → critic gate）

producer→ critic gate

gate 读 upstreamNodeId=producer 输出，断言含「修订/反驳」，失败回退重跑 producer（对抗循环）。
