🏗️ 架构设计

宿主端 Redis 桥接（零侵入 agent-runner）

Pod B (用户连接)                         Pod A (agent 运行)
──────────────────                       ──────────────────
GroupQueue.sendMessage()                 IpcWatcherManager.watchGroup(folder)
  │ state = null (无本地 agent)            │ Redis connected
  │ Redis connected                        ▼
  ▼                                       subscribeAgentIpc(folder, handler)
publishAgentIpc(folder, payload)          │
  │ Redis pub/sub                          │ handler writes local file
  ▼ ─────────────────────────────────────▶ │
  deepthink:ipc:{folder}                  ▼
  │                                       data/ipc/{folder}/input/{ts}.json
  │                                       │
  │                                       ▼ agent-runner reads via fs.watch
  │                                       drainIpcInput() / waitForIpcMessage()

控制信号 (_close/_drain/_interrupt):
  Pod B → publishAgentIpc(folder, {type:'_close'}) → Redis → Pod A handler writes _close sentinel

Agent Runner 分布式模式

K8s agent-runner Deployment (独立 Pod)
  │
  ├── REDIS_URL=redis://redis:6379
  ├── AGENT_RUNNER_MODE=distributed
  │
  ▼ main()
  initRedisIpc() → 连接 Redis, 注册到 agent-runners:pool
  waitForTask() → 从 deepthink:agent-tasks 获取任务 (替代 stdin)
  subscribeIpcInput(folder) → 订阅 deepthink:ipc:{folder} (替代 fs.watch)
  │
  │ shouldClose/shouldDrain/shouldInterrupt → 优先检查 Redis 队列
  │ drainIpcInput → 合并 Redis 消息 + 文件消息
  │ writeOutput → stdout + Redis publishIpcOutput
  │
  ▼ 进程退出, K8s 重启 Pod 等待下一个任务
