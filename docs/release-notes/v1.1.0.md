# DeepThink v1.1.0 发布说明

> 自托管的多用户本地 AI Agent Loop Engineering 系统（支持桌面端 + 浏览器 + 移动端）
> Powered By AI Genius Institute，AI 光剑

发布日期：2026-08-07

v1.1.0 是一个**自主性跃迁**版本——DeepThink 从"工具使用者驱动的 Loop Engineering"进化到"自主感知→决策→执行→学习→维护全闭环的自主 Agent 系统"。本版本交付两块拼图：**自主 AI Agent 系统升级（Autonomy Layer + 度量埋点 + 验收套件）** 与 **全托管模式（Autonomous Mode）**，并修复桌面版打包的依赖漏洞。

## ✨ 新功能

### 一、自主 AI Agent 系统升级（Autonomy Layer）

在已合并的 5 个自主相关 PRD（self-evolving-harness / loop-engineering-v3 / supervisor-longrunning / super-agent-team / graph-engineering）之上，新增横切 **Autonomy Layer**，把分散的 7 大能力收口为可度量、可验收、可闭环的统一系统，并补齐量化度量与无人工干预 E2E 验收。6 个工作包全部交付：

| WP | 内容 | 阶段 | 状态 |
|---|---|---|---|
| WP1 | 自主性中枢（事件总线 + 能力注册表 + 7 能力模型） | P0 | ✅ |
| WP2 | 度量埋点 + 采集 + 聚合（8 指标口径 + API） | P0 | ✅ |
| WP6 | 验收套件骨架（Playwright E2E） | P0 | ✅ |
| WP3 | 学习接入主循环（graph_run → lesson 沉淀 + 检索） | P1 | ✅ |
| WP4 | 主动适应（信号 → 处理 → 适应速度指标） | P1 | ✅ |
| WP5 | 自愈 + 预测预警 + 仪表盘 | P2 | ✅ |

**7 大能力采集闭环**：

| 能力 | 度量口径 | 状态 |
|---|---|---|
| ①自主感知 | `perception.active_trigger → proactivity_ratio` | ✅ |
| ②自主认知 | 复用 supervisor-agent 决策 + harness-eval 断言 | ✅ |
| ③自主决策 | `decision.generated human_triggered=false → decision_independence` | ✅ |
| ④自主执行 | `execution.completed` success/fail + retry/recovery 既有 | ✅ |
| ⑤自主学习 | `learning.promoted(latency_ms)` + lesson 沉淀/检索 | ✅ |
| ⑥自主适应 | `adaptation.adjusted(latency_ms)` + adapt loop | ✅ |
| ⑦自主监控 | `monitoring.predicted` + `self_healed` | ✅ |

**关键 API**：`GET /api/autonomy/capabilities`（7 能力注册表）、`GET /api/autonomy/metrics`（指标聚合）、`GET /api/autonomy/health`（健康）、`POST /api/autonomy/signals` + `POST /api/autonomy/signals/process`（信号→适应闭环）、`GET /api/autonomy/lessons`（学习沉淀）。

**Schema 迁移**：SCHEMA_VERSION 53→54，4 表 `IF NOT EXISTS` 幂等，不动既有列。

**诚实说明**：本版本建立了全部 7 能力的**指标采集口径 + 落库 + 聚合 API + 验收断言闭环**——埋点→事件→metrics 表→aggregateMetric→API→E2E 断言。E2E 与单测验证了**采集闭环可工作**（注入可控信号后指标正确落库 + ratio 正确计算 + denominator=0 返回 null 不 NaN）。实际达标率（如 ≥95% 主动性）取决于真实业务流量下的分子分母积累——骨架已就绪可量化，全标达标待真实流量。详见 `docs/test_report/autonomy-system/REPORT.md`。

### 二、全托管模式（Autonomous Mode）

新增全托管模式作为 DeepThink 的连续推进开关：Agent 一旦进入任务即全自主完成，覆盖三道防御层（CLAUDE.md Think Before Coding 宪法、Supervisor clarify 路径、RLHF 端回合礼貌），并加入四道硬刹车护栏保证自主性的同时最小化风险。

**三道防御层覆盖**：
1. **CLAUDE.md 宪法层**：向 agent-runner 注入 `Autonomous Override` 段（含 6 条规则：禁止向用户提问、禁用 AskUserQuestion、必须填写 `<assumption>`、循环检测、硬刹车、任务无法完成时的处置）。
2. **Supervisor clarify 旁路**：`supervisor.ts parseDecision` 在 autonomous 时把 `clarify` 降级为 `delegate`，question 被丢弃（`reason='autonomous_downgrade'`），若原 clarify 携带 `instruction` 则保留。
3. **RLHF 端回合礼貌**：agent-runner 主循环端回合检测——`AskUserQuestion` tool 调用作为强信号 + `ASKING_PATTERNS` 弱信号，命中后自动续接而不打断。

**四道硬刹车护栏**：
- **破坏性命令检测**（`DESTRUCTIVE_PATTERNS`）：14 个正例覆盖 `rm -rf /`、`git push --force`、`git reset --hard`、`DROP TABLE/DATABASE`、`TRUNCATE`、`DELETE FROM` 无 WHERE、`mkfs.*`、`dd to /dev/`、fork bomb 等；10 个反例避免误杀 `rm -rf ./build`、`git push --force-with-lease`、guarded `DELETE ... WHERE` 等。
- **轮次上限**：超过最大轮次强制停止。
- **token 上限**：超过 token 预算强制停止。
- **循环检测**：滑动窗口尾部 3 条相同 turn 触发（hash 仅取前 5000 字符，确定性）。

**数据流与持久化**：
- per-group 配置 + per-message 覆盖（`true` / `false` / `null`）
- `messages.autonomous` / `scheduled_tasks.autonomous` 列
- API：`GET/PUT /api/config/autonomous`、`GET /api/config/autonomous/all`

**前端体验**：
- `AutonomousToggle` 开关 + `AutonomousStopButton` 硬刹车按钮 + `CreateTaskForm` checkbox
- 4 个新 StreamEvent：`autonomous_started` / `autonomous_continued` / `autonomous_aborted` / `autonomous_brake`
- chat store 完整事件处理
- **UI 显式展示全托管状态**：持久 banner + 消息火箭角标，让"Agent 正在全自主推进"的状态在长任务中始终可见

**测试**：49 单测（5 文件覆盖 clarify 旁路、模式检测、配置持久化、CLAUDE.md 注入、Schema 校验、循环检测）+ 20 E2E（autonomous-mode 14 + autonomous-brake 6）+ 三端 tsc + StreamEvent 同步校验全绿。详见 `docs/test_report/feat-autonomous-mode/TEST_REPORT.md`。

## 🐛 缺陷修复

### 桌面版打包：web 依赖未装导致失败

`make desktop-pack-mac` 不会自动安装 web 依赖，干净环境或拉新分支后报 `Cannot find module '@monaco-editor/react'`（此前 commit 974bd38 加了 monaco-editor 到 `web/package.json`）。新增 `web-install` 目标（带 mtime 守卫避免重复安装），并挂到 `desktop-build-deps` 前置链。详见 `docs/issues/`。（`a2f78f3`）
